01

About

The longer version, with the full project history, lives at cv.havocsec.me.

I'm a cybersecurity student and self-driven security researcher who learns by breaking. Most of my time goes to bug bounty programs, CTF competitions and labs: live targets, real scope, no passive learning.

One deliberate decision shapes everything here: cybersecurity is the core, and development is a supporting weapon, not the destination. That focus is why this portfolio is narrow on purpose.

I document what I learn, including the failures, and iterate aggressively. The long game is to be a bug bounty hunter and researcher whose work speaks through findings, writeups and tools, not buzzwords.

Capabilities

Web & API

SSRF and filter bypasses, command injection, XSS, access-control flaws. Burp Suite, OWASP Web and API Top 10 methodology.

Active Directory

Kerberos abuse, ADCS escalation paths (ESC1 to ESC13), delegation attacks, cross-domain trusts. BloodHound, Impacket, NetExec.

Linux & containers

SUID and sudo abuse, TOCTOU race conditions, Docker escapes, kernel assisted privilege escalation.

Cryptography

RSA lattice and fault attacks, broadcast weaknesses, ECDSA side channels, hash length extension.

Forensics & RE

Memory and disk forensics with Volatility3, EVTX analysis, Ghidra, .NET reversing, ransomware analysis.

Build
